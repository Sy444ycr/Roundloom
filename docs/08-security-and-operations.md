# 安全、运行与质量要求

> 2026-11-13 更新：首发形态已确定为桌面应用。本文涉及本地 Web 首发的内容为历史候选，桌面进程、通信和生命周期以[桌面架构选型](09-desktop-architecture.md)为当前推荐；其余业务语义继续有效。

版本：v0.2 评审草案｜日期：2026-11-13

## 1. 信任边界

用户、浏览器、本地服务、适配器、Agent 及 Agent 返回内容属于不同信任边界。群消息、仓库文件和远程产物可能含不可信指令，不能据此提升工具权限或改变成员身份。

本地 Web 方案如获采用，建议服务默认仅监听回环地址；浏览器会话使用认证并校验来源，写操作具有跨站请求防护。群聊工具凭证绑定成员、房间和允许操作，支持撤销；模型提交的 senderId 不作为授权依据。

工作区授权记录允许根目录和操作类型。平台文件访问应校验规范化路径及符号链接后的实际目标，拒绝路径穿越。远端路径只作为远端引用；补丁需核对仓库、基准版本及目标范围，应用冲突显式报告。

worktree 不是沙箱。原生 Agent 的执行权限由其运行机制约束；若平台无法强制限制，应展示真实边界，不能声称已隔离。首版是否需要额外执行沙箱见 O-08。

凭据保存在系统凭据存储或受限配置中，业务对象仅保存引用；不得写入共享消息、上下文、普通日志或导出包。错误与命令日志应脱敏，诊断导出提供内容预览。第三方适配器属于可执行代码，首版建议只加载显式配置的本地适配器，不自动下载安装。

## 2. 质量目标登记

以下是待测目标，不是性能承诺。数值由 M1 基准测量和 M2 实测确定，M3 前固定验收阈值。

| 指标 | 测量方法 | 确定时点 |
| --- | --- | --- |
| 成员数、并发运行数、事件规模 | 固定机器与样例负载，记录队列和界面响应 | M1 出口 |
| 消息持久化及界面可见延迟 | 同一请求端到端采样，报告样本量及分位数 | M1 出口 |
| 重连补齐耗时 | 固定事件数量，断开后按游标补齐，检查无遗漏和重复 | M1 出口 |
| 原生取消与恢复耗时 | 按适配器分别测量，未知及不支持单列 | M2 出口 |
| 协作时间与调用预算 | 固定样例任务，统计实际调用和等待；费用缺失保持未知 | M3 入口 |

不依赖数值的正确性要求立即作为验收草案：已确认持久化的记录在进程异常退出后可恢复；历史重放不触发执行；任务与来源消息不出现半提交；敏感字段不进入普通导出。磁盘故障和文件系统损坏的恢复能力不等同于进程崩溃恢复。

## 3. 开发与交付约定

开发阶段补充环境版本、依赖锁文件、启动命令、配置示例和数据库迁移说明。配置示例不得含真实密钥。每项变更关联需求或缺陷、验证结果和已知限制；接口变化同时更新契约。

日志使用 roomId/taskId/runId/requestId 关联事件，区分平台错误、适配器错误与用户取消。数据备份应覆盖数据库、产物及版本信息；恢复前停止写入，恢复后先核对原生运行，不能自动重放副作用任务。保留时长和清理规则见 O-09。

发布检查至少包含安装启动、迁移或回退、核心回归、兼容矩阵、已知问题和诊断说明。没有真实证据的能力仍标为未验证。当前仅编写文档，不执行安装或真实 Agent 调用。
